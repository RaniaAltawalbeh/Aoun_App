# Aoun (عون)

> A smart national platform developed for the **Crown Prince Award for Best Government Application**, connecting citizens with competent authorities to transform incident reports into actionable data for faster emergency response and informed decision-making.

---

## Key Value

* **For Citizens:** Simplified, low-stress incident reporting with real-time location precision.
* **For Authorities:** Faster dispatch, accurate incident data, and live situational awareness.
* **For Decision-Makers:** Data-driven heatmaps, operational KPIs, and predictive resource planning.
* **For the State:** Reduced infrastructure damage, minimized waste, and optimized public spending.

---

## Tech Stack

* **Frontend:** Flutter, Dart
* **Backend:** Node.js / NestJS, REST APIs
* **UI/UX Design:** Figma
